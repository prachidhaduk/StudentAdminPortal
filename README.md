# Student Admin Portal

A web-based Student Administration Portal developed using ASP.NET MVC, C#, Entity Framework and SQL Server.

## Features

- Student Management
- Course Management
- Subject Management
- Marks Management
- Attendance Management
- Admin Login & Logout
- Dashboard
- Student Search/Filter
- Marks and Grade Management
- Attendance Tracking
- CRUD Operations

## Technologies Used

- C#
- ASP.NET MVC
- Entity Framework
- SQL Server
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery

## Database

The project uses Microsoft SQL Server with the following main tables:

- Users
- Students
- Courses
- Subjects
- Marks
- Attendance
